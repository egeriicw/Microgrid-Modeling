# Requirements Traceability Matrix

Last verified against the repository: 2026-11-19

Maintained by the Business Analyst role (see `agent-team.md`). A requirement is **Done** only when it has a green
test, merged code, and updated docs. Generated from `docs/PRD.md` on 2026-11-06; statuses re-established from the
repository (tests that exist and exercise the acceptance criteria, plus code that exists) on 2026-11-17; Wave 1 batch 1
rows (FR-ENG-4/10/11/13, FR-WEB-1/2/5/8, FR-PLAT-2/4) updated 2026-11-19.

Status words: **Done**, **Partial** (the note says which acceptance criteria are met and which are not), **Not started**.
A skipped, xfail or placeholder test is not evidence. Paths in Tests and Code are relative to the repo root unless
stated: engine code is under `src/microgrid/`, API code under `api/src/microgrid_api/`, API tests under `api/tests/`,
web code and tests under `web/src/`.

Cross-cutting notes: story 1.12 (chart spike) supports the FR-WEB chart requirements; evidence is
`docs/research/echarts-spike.md` (cloud-VM measurements only, QA pending). The web app now selects its client in
`web/src/api/select.ts` (called from `web/src/main.tsx`): the real HTTP client `web/src/api/httpClient.ts` by default,
the mock client (`web/src/api/mockClient.ts`) only when `VITE_API_MODE=mock`. Web tests for the real client stub `fetch`
(`web/src/qa/w1web-*.test.ts(x)`); `web/e2e/run-lifecycle.spec.ts` and `web/e2e/qa-real-api.spec.ts` are Playwright specs
that no CI job runs (not evidence). Known gaps against the real API: custom compositions cannot run (only predefined
ones), and the API has no caller-identity endpoint, so the real client holds a null session role. Everything here is
verified on fixtures only (not on real data) and not on macOS/arm64 or Docker locally. Placeholder tests that do not
count as evidence: `api/tests/test_runs_api.py`, `test_configs_api.py`, `test_scenario_validation_api.py`,
`test_storage.py` (all xfail or import-skipped) and `scripts/tests/test_download_oedi.py` (xfail, import-skipped).
